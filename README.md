## 🌌 About The Project

**CalorieFit** is a modern **Premium Nutrition & Fitness Calculator** built using **HTML, CSS, and JavaScript**. It helps users estimate their daily calorie needs, calculate **BMI, BMR, TDEE**, monitor macronutrients, and receive personalized calorie recommendations for **weight loss, maintenance, or muscle gain**.

Designed with a **Luxury Neon Blue UI**, glassmorphism cards, smooth animations, responsive layouts, and a premium fitness dashboard experience.

> **Transform your health goals into measurable daily nutrition plans.**

---

# ✨ Premium Features

| Feature                      | Description                                                               |
| ---------------------------- | ------------------------------------------------------------------------- |
| 🍽️ Daily Calorie Calculator | Calculate calories based on age, gender, height, weight & activity level. |
| ⚖️ BMI Calculator            | Check Body Mass Index with health category.                               |
| 🔥 BMR Calculator            | Calculate Basal Metabolic Rate using Mifflin-St Jeor Formula.             |
| 💪 TDEE Calculator           | Estimate Total Daily Energy Expenditure.                                  |
| 🎯 Goal Calories             | Calories for Weight Loss, Maintain, and Weight Gain.                      |
| 🥗 Macronutrient Split       | Protein, Carbs, and Fat recommendations.                                  |
| 💧 Water Intake Calculator   | Daily hydration requirement.                                              |
| 📊 Interactive Results       | Animated progress bars and statistic cards.                               |
| 🌙 Dark / Light Mode         | Elegant Neon Blue Theme Toggle.                                           |
| 📱 Fully Responsive          | Desktop, Tablet, and Mobile Friendly.                                     |
